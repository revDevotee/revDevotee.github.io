AWEngine

ECS Architecture

AWEngine uses the ECS pattern to separate data and logic. All examples are just examples, and they are written to be AS SIMPLE AS POSSIBLE.

EcsEntity

  • EcsEntity is a unique container for components. It has methods such as:

    • EcsEntity.AddComponent(EcsComponent component) Adds a component to the entity. Supports method chaining (EcsEntity.AddComponent(EcsComponent component).AddComponent(EcsComponent component)).

    • EcsEntity.RemoveComponent<T>() where T : EcsComponent Removes a component from the entity. Also supports method chaining.

    • EcsEntity.SwapComponent<T>(EcsComponent S) where T : EcsComponent Replaces component T with component S. Added so you don't have to write "remove this component and add that component" twice.

    • EcsEntity.GetComponent<T>() where T : EcsComponent Gets component T from the entity to work with its contents.

    • EcsEntity.HasComponent<T>() where T : EcsComponent Returns true if component T exists in the entity.

Example with EcsEntity:

var hero = new EcsEntity();
hero.AddComponent(new Info { Name = "Hero", Description = "Really cool guy"} );
hero.AddComponent(new Respect());
hero.AddComponent(new Inventory { Space = 10 } );

if (2+2 != 5) 
{
    hero.SwapComponent<Respect>(new Disrespect());
}

if (hero.HasComponent<Respect>())
{
    hero.GetComponent<Inventory>().Space = 20
}
else
{
    hero.RemoveComponent<Inventory>();
}

EcsComponent

  • EcsComponent represents pure data (inherits from EcsComponent).

Example with EcsComponent:

public class Respect : EcsComponent //You can even leave them empty if you want to use them as a marker, or honestly, just do whatever you want.
{

}

public class Inventory : EcsComponent
{
    public int Space { get; set; }
}

EcsSystem

  • EcsSystem handles game logic processing entities. Registered via SystemManager by execution phases (ExecutionPhase).

    • Child classes MUST implement public override void Update(IReadOnlyList<EcsEntity> entities).

Example with EcsSystem:

public class AOEDamage : EcsSystem
{
    public override void Update(IReadOnlyList<EcsEntity> entities)
    {
        var mainHero = entities.FirstOrDefault(s => s.HasComponent<MainHero>());
        foreach(EcsEntity entity in entities)
        {
            if (entity.HasComponent<Enemy>())
            {
                entity.GetComponent<Stats>().HP -= mainHero.GetComponent<Stats>().AOEDamage
            }
        }
    }
}

WorldContext

  • WorldContext is the storage for all active entities (EcsEntity) in the world. It has the following methods:

    • WorldContext.AddEntity(EcsEntity entity) Adds a new entity to the storage.

    • WorldContext.Cleanup<T>() where T : EcsComponent Deletes all entities that have component T (for example, if you created a Remove component, all entities having this component will be deleted when this method is called).

Example with WorldContext:

var wc = new WorldContext();
var hero = new EcsEntity();
var enemy = new EcsEntity();

hero.AddComponent(new MainHero()).AddComponent(new Stats{ HP = 100, Damage = 50});
enemy.AddComponent(new Enemy()).AddComponent(new Stats{ HP = 30, Damage = 15});

wc.AddEntity(hero);
wc.AddEntity(enemy);

var mainHero = entities.FirstOrDefault(s => s.HasComponent<MainHero>());
var enemy = entities.FirstOrDefault(s => s.HasComponent<Enemy>());

if(enemy.GetComponent<Stats>().HP - mainHero.GetComponent<Stats>().Damage <= 0)
{
    enemy.AddComponent(new Remove());
}
else
{
    Console.WriteLine("Enemy: ez");
}

wc.Cleanup<Remove>();

SystemManager

  • SystemManager is the storage for all registered systems (EcsSystem) sorted by execution phases (ExecutionPhase). It has methods:

    • SystemManager.Add(ExecutionPhase phase, EcsSystem system) Adds a system to the list for a specific execution phase type. Supports overloading and can accept a List<EcsSystem> instead of a single system.

    • SystemManager.Remove(ExecutionPhase phase, EcsSystem system) Removes a system from the list for a specific execution phase type.

    • SystemManager.Update(WorldContext wc, ExecutionPhase phase) Executes all registered systems for the specified execution phase type.

Example with SystemManager:

public static class GameSystems
{
    public static ExecutionPhase render = new ExecutionPhase();
    public static ExecutionPhase input = new ExecutionPhase();
}

var wc = new WorldContext();
var sm = new SystemManager();
systems.Add(GameSystems.input, new GetButton());
systems.Add(GameSystems.render, new MainMenu());

var ui = new Entity();
ui.AddComponent(new MainMenuUI())
wc.AddEntity(ui);

sm.Update(wc, GameSystems.input);
sm.Update(wc, GameSystems.render);
