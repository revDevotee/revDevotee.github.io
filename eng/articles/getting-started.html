    Getting started

    To get started with AWEngine, you need to create a class that inherits from the abstract AWEngine class and implement the mandatory Init() and Update() methods. But of course, you can choose not to use my methods and write your own loop and stuff, and the only thing you'll lose is the splash screen and simple error output :c Use my method. Please 😭😭😭

    Example of a minimal project

    using System;
using AWEngine;

class Program
{
    static void Main(string[] args)
    {
        MyGame game = new MyGame();
        // Run engine(FastSplash: true, if you want to skip splash screen faster. False by default)
        game.Run(FastSplash: false);
    }
}

public class MyGame : AWEngine.AWEngine
{
    protected override void Init()
    {
        Console.WriteLine("Loading game...");
        // Here you can create entity, systems, and register them in worldcontext and systemmanager, or uhh anything you want
    }

    protected override void Update()
    {
        // Main game cycle
        Console.WriteLine("Game loaded, maybe");
        // if you want to exit game, you can change this state to false(true by default)
        running = false; 
    }
}

    SplashScreen

    The engine supports a colorful splash screen. You can trigger it manually, or it will run automatically when calling the Run() method:

    FastSplash = false - displays a full ASCII-art banner and an animated initialization process with a spinner (-, , |, /).

    FastSplash = true - fast text output for 1.5 seconds.
