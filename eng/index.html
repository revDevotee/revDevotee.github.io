AWEngine

AWEngine Documentation eng

AWEngine is a lightweight, custom C# game engine implementing the ECS (Entity-Component-System) pattern, made by revDevotee.

All rights are NOT reserved! :D

Key Features

  • Custom ECS Architecture: Flexible separation of data (EcsComponent, EcsEntity) and logic (EcsSystem).
  • Execution Phases: Control system execution order via SystemManager.
  • (Un)reliable Error Handling: Built-in exception handling mechanisms operating at both the engine game loop level and isolated within each system.
