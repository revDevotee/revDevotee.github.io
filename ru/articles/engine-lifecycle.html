Жизненный цикл и ошибки

Метод Run(bool FastSplash = false) управляет полным жизненным циклом движка, последовательно проводя приложение через стадии инициализации, работы основного цикла и безопасного перехвата возможных сбоев.

Порядок выполнения

  1. Заставка (SplashScreen)
    Отображает стартовый экран движка. Поведение зависит от параметра FastSplash:

    • false (по умолчанию): Выводит фирменный ASCII-арт, информацию об авторстве (AWEngine by revDevotee) и запускает анимированный индикатор загрузки с иконкой вращения (-, \, |, /).
    • true: Пропускает анимацию и ASCII-арт, выводя короткую строку текста с задержкой в 1.5 секунды для ускоренного запуска.

  2. Инициализация (Init)
    Вызывает защищенный абстрактный метод Init(). На этом этапе дочерний класс обязан реализовать всю необходимую пользовательскую подготовку (загрузку ресурсов, создание стартовых сущностей и т.д.).

  3. Основной цикл (Update)
    Запускает непрерывный процесс в блоке while (running). Итерации выполняются до тех пор, пока флаг running имеет значение true. Изменение этого флага извне позволяет штатно остановить работу движка.

Обработка критических ошибок

Весь жизненный цикл движка (от заставки до завершения Update) обернут в защитный блок try-catch, предотвращающий внезапный аварийный выход из программы без логирования:

  • При возникновении любого необработанного исключения (Exception ex) консоль очищается (Console.Clear()).
  • Движок формирует и выводит на экран структурированный отчет о критической ошибке:
    • [SOURCE] — источник ошибки (сборка/модуль).
    • [TYPE] — полное имя класса исключения.
    • [MESSAGE] — текст ошибки.
    • [STACKTRACE] — подробный стектрейс вызовов.
  • Работа программы приостанавливается до нажатия любой клавиши пользователем (Console.ReadKey()), позволяя прочитать информацию о сбое.
